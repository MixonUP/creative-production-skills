# Preference experiments
These are practical proposed protocols, not validated universal beauty metrics.

## Two comparison tracks
A. Original artwork board: preserves what made the reference compelling.
B. Controlled remake board: same original adult character, crop, expression, light, outfit complexity and image size across candidate visual languages. This separates style preference from subject/presentation preference.

Ask separate questions: instant appeal; memorable identity; personality; desire to interact; comfort after a longer dialogue. Allow “tie” and “neither.” Randomize left/right and occasionally repeat pairs to detect unstable judgments. User choices, not invented weights, drive shortlist.

Use a broad first pass followed by comparisons among favorites. Do not force all N*(N-1)/2 pairs. Aggregate wins with comparison counts and uncertainty; sparse rankings should not imply precise absolute scores. A single user's ranking establishes personal taste, not market demand.

## Interaction test
For final 3–5 directions, compare a neutral portrait and equivalent short performances: smile, skeptical glance, speaking, head turn. Keep script, timing and framing comparable. Evaluate face drift, eye contact, mouth deformation, expression legibility and comfort. Still-image favorites can change in motion.

## LoRA handoff
Keep a style test separate from identity fidelity. Use held-out characters and scenes to see whether the visual language transfers beyond memorized compositions. Record model/checkpoint/weight/seed/settings only from actual runs. A successful reference image is not proof of reproducible animation or a completed training run.
