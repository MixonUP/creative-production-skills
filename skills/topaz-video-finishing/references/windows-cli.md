# Windows CLI: воспроизводимый запуск

Topaz использует собственную сборку FFmpeg. Общий FFmpeg полезен для доставки и измерений, но не заменяет бинарник с `tvai_*`. [Старая официальная CLI-справка](https://docs.topazlabs.com/video-ai/advanced-functions-in-topaz-video-ai/command-line-interface) объясняет окружение; актуальные опции определяет наша установленная сборка.

## Подготовка без рендера

`scripts/prepare_baseline.py SOURCE OUTPUT.mov --sdr-confirmed --save PLAN.json`

Скрипт читает метаданные CPU ffprobe и help Topaz, проверяет наличие `prob-4.json`, выдаёт argv и окружение дочернего процесса. Выход: planned_not_rendered. Поддерживаемая область намеренно узкая: один progressive H.264 8-bit yuv420p/nv12, square pixels, SDR, 2x, без изменения частоты. В `--sdr-confirmed` агент передаёт уже установленный факт из происхождения/проверки изображения; это не средство переименовать неизвестный HDR в SDR. Известный PQ/HLG/BT.2020 скрипт отвергает. Для другого входа составить отдельный рецепт.

Проверка `r_frame_rate == avg_frame_rate` не доказывает CFR: план сохраняет предупреждение, требуется PTS-проверка перед монтажом чувствительного к таймингу материала. `--save` создаёт новый JSON; существующий файл не перезаписывается. Скрипт не выполняет argv, не обращается к Resolve, не скачивает модели и не меняет системное окружение. План нельзя считать тестом inference.

В историческом Seedance original отсутствует SAR-тег. Для его уже применявшегося вида 992×432 можно явно добавить `--assume-square-pixels`: план запишет интерпретацию, а команда — `setsar=1`. Это не обнаруженный метаданный факт. Флаг не переопределяет известный non-square SAR; такой вход требует другого рецепта.

При разрешённом рендере запускать `subprocess.Popen(argv, env=child_env, shell=False, ...)` с логом в папке новой версии. Не вставлять JSON argv в shell как строку. Повторно проверить source size/mtime или hash, отсутствие output и доступность GPU непосредственно перед запуском. `-n` защищает существующий output. Не применять `-y`, `-an`, `-r 60`, `-shortest` по привычке. Не запускать план, полученный из непроверенного внешнего файла.

Для нового материала первый GPU-запуск — короткий представительный фрагмент. Для baseline всего исторического 11-секундного теста можно использовать весь клип, если пользователь просит обработку. Обрезку делать с явным контрактом integer frames и синхронным аудио; не считать приблизительное seek доказательством точного диапазона.

## Model data и аппаратные кодеки

Проверять definitions и веса отдельно. JSON с displayName — каталог доступных вариантов, а не выполненный model download. `TVAI_MODEL_DIR` — определения, `TVAI_MODEL_DATA_DIR` — данные; если GUI хранит их раздельно, передать отдельные пути. Не копировать auth/лицензию и не править модельный JSON ради доступности. CLI обязан использовать штатную активацию установленного продукта.

У нас `h264_cuvid` и `prores_ks` сработали на H.264 8-bit. Это не основание навязывать decoder любому HEVC/ProRes/10-bit входу. Для иной кодировки проверить `-decoders` и соответствующий software/hardware path. В локальном Topaz отсутствует `libx264`; delivery H.264 делали `C:/FFmpeg_exe/ffmpeg.exe` после ProRes-мастера. Не переносить `h264_videotoolbox` из macOS-урока на Windows.

## Разбор ошибок

| Симптом | Следующий обоснованный шаг |
|---|---|
| `No such filter: tvai_up` | Проверить абсолютный путь бинарника; не переустанавливать Resolve |
| `Unknown encoder libx264` | Локальный `-encoders`; ProRes HQ master, отдельный delivery encoder |
| QSV/decoder init error | Наш исторический H.264 исправлен явным cuvid; для другого входа выбрать реально поддерживаемый decoder |
| Model not found / download disabled | Проверить GUI-selected model/version и две папки; показать недостающие данные, не включать загрузку молча |
| Licence/activation failure | Проверить штатный GUI-вход/право CLI, не читать или менять auth; прекратить повторные неуспешные GPU-запуски |
| OOM / model instance failure | Учесть активные GPU-процессы, уменьшить параллелизм/память или размер теста; не останавливать чужой job |
| Starlight обычный Preview не работает | Для поддерживаемой модели короткий Export; сверить Neuroserver и требования именно этого варианта |
| OFX отсутствует в Free | Использовать standalone round trip; официально нужен Studio, Resolve не обновлять |
| После таймаута неизвестен статус | Сначала проверить PID/log/файл; не запускать второй тяжёлый процесс |
| Есть output, процесс упал | Пометить partial; сохранить лог, QC, новая версия при повторе. Не импортировать как принятый master |

Один разумный повтор после исправления установленной причины; при повторении той же ошибки остановить серию и сообщить конкретный блокер. Не менять драйвер, приложение или окружение обучения как автоматическое «исправление».
