# Topaz → Resolve через наш MCP

## Сохранить монтажный контракт

Для обычной доводки не менять FPS и продолжительность. ProRes 422 HQ 10-bit + PCM — наш проверенный промежуточный формат; 10-bit encode не создаёт отсутствующий динамический диапазон 8-bit исходника. Сохранить SAR/DAR и число кадров; custom wide размер 1984×864 не нужно растягивать до 16:9. Delivery H.264 — отдельный финальный encode после мастера.

Зафиксировать исходные color_range / color_space / color_transfer / color_primaries и реальное происхождение. Если теги отсутствуют, не выдумывать подтверждённый Rec.709. Если картинка уже SDR с запечённым видом, не применять второй display transform. HDR/PQ/HLG/log и анаморфный источник требуют отдельной проверенной конвертации. Простая запись тега BT.709 не преобразует цвет. После возврата проверить black/white levels, оттенки кожи и яркость в одном управляемом контексте.

Звук: обычный enhancement меняет изображение; сохраняя звук, явно map все требуемые аудиодорожки. PCM48k — ресэмплинг/кодирование, а не битовый copy и не восстановление речи. Не заменять оригинальные стемы одним миксом. Таймкоды/метаданные/субтитры могут потребовать отдельного переноса; не обещать их сохранность без проверки.

## Интерполяция и slow motion — отдельное решение

[Официальная документация](https://docs.topazlabs.com/topaz-video/filters/frame-interpolation) предупреждает об исключении аудио в интерполированном выходе. Сохранять оригинальный звук отдельно и проверить реальный экспорт нашей версии. При неизменной длительности его можно синхронно вернуть; при замедлении нужен согласованный audio retime/новый звук, а не автоматическое удаление.

Для нашей CLI `tvai_fi` default model — **chr-2**, не apo-8. Всегда задавать выбранную модель явно. `slowmo` 0.1…16, `fps` — rational output rate. `rdt` −0.01…0.2 — **порог замены дубликатов**, не сцены; <=0 выключает replacement. Не удалять повторяющиеся кадры намеренной анимации автоматически. Смена кадровой частоты и замедление имеют разные последствия для длительности.

Для D секунд при выходном F fps и замедлении S ориентир N≈D×F×S; точное целое число и пограничные кадры измерить на выходе. Разделять планы по монтажным склейкам до интерполяции, чтобы модель не строила переход между разными сценами. Стабилизацию и motion deblur включать по дефекту: они могут изменить crop, края и рисунок движения; не применять обязательной цепочкой ко всему фильму.

## MCP-процедура

Использовать доступные схемы `resolve_krea`, а не выдуманный Topaz server. Наблюдаемые действия каталога на 30.09.2026: `media_pool.safe_import_media`, `append_to_timeline`, `timeline.get_current`, `get_items`, `probe_timeline_structure`, `detect_gaps_overlaps`, `duplicate`. Сначала прочитать help требуемого действия; названия без текущих схем не являются готовой сигнатурой.

1. Считать текущий project/timeline identity и выбрать целевой по заданию. Не менять случайно открытый проект. Перед перестройкой сделать новую версию таймлайна; одна запись в проект одновременно.
2. Импортировать только прошедший QC master в отдельный bin, используя проверяемый import с dry_run, затем явным выполнением в рамках задачи. Новый media path и уникальная версия предотвращают подмену исходника.
3. При создании нового таймлайна задать FPS до добавления клипов, прочитать обратно фактически применённое значение. `timelinePlaybackFrameRate` исторически вернул false: не считать его установленным по ожиданию.
4. Диапазоны SOURCE и RECORD FRAME — разные координаты. В нашем импорте 21.09 endFrame оказался exclusive; current checked API сообщает свои соглашения. Проверить реальную длительность, не распространять один convention на все методы. WAV source_fps может отличаться от timeline fps.
5. После вставки считать пути media, начала/длительности, video/audio tracks, gaps/overlaps и итоговую длину. После таймаута проверить уже добавленные clips до повторного append. Сохранить проект и отчёт с ID и именами.
6. Смотреть на кадр/рендер из Resolve. Source thumbnail не доказывает применение grade/Fusion. Для сравнения эффекта использовать rendered frame либо поддерживаемый gallery export; слушать звук с изображением.

Исторический `Tools/ResolveMCP/import_topaz_finish.py` содержит конкретные имя проекта/пути. Он — свидетельство успешного маршрута, **не универсальный скрипт для повторного запуска на другом проекте**.

При SCRIPTING_UNAVAILABLE прочитать `Tools/ResolveMCP/README.md`: после перезапуска Resolve нужен существующий `resolve_bridge_18463` из Workspace → Scripts. Не запускать второй экземпляр Resolve и не устанавливать 21.1+. Конфигурация моста содержит секрет: не публиковать её. Read-only skill research не требует запускать хост лишь ради live-probe.
