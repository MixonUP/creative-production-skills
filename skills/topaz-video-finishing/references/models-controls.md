# Выбор модели и управление деталями

Дата источников 30.09.2026. Ниже — назначения из официальной документации и кандидаты для наших опытов. Победитель определяется на конкретном движущемся плане.

## С чего начинать сравнение

| Задача | Кандидат | Что проверять |
|---|---|---|
| Обычный AI-ролик, умеренные дефекты | Proteus `prob-4`, наш 2x baseline | Контуры лица, волосы, сохранение фактуры |
| Более мягкая реконструкция | Proteus Natural `pnat-1` | Сравнить с Proteus на одинаковом размере; локальный JSON задаёт scale 2 |
| Шум при сохранной структуре | Nyx `nyx-3`; для HQ также Nyx XL `nxl-1` | Потеря текстуры/теней; Nyx XL имеет scale 1 в локальном JSON |
| Разрушенные мелкие лица | Iris `iris-3` | Личность, глаза/зубы; усиление деталей может перерисовать лицо |
| Детализированный 4x | Rhea `rhea-1` / Rhea XL `rxl-1` | Мелкие узоры, мерцание; 4x не заменяет отсутствующий исходный материал |
| Уже чистая CG/анимация | Gaia, либо отсутствие AI-прохода | Сохранение линий и стилизации |
| Сжатый архив | Artemis или deinterlace-модели при настоящих полях | Сначала определить тип полей и SAR |

Назначения: [Enhancement](https://docs.topazlabs.com/topaz-video/filters/enhancement). Наличие перечисленных JSON подтверждено локально; выполнение всех этих моделей — нет.

## Starlight: перспективная ветка для нашего AI-видео

[Starlight Precise 2.6](https://docs.topazlabs.com/topaz-video/project-starlight-series/starlight-precise-25) — кандидат для искусственной кожи и мягких фактур при уже правильной геометрии. Вендор указывает доступность с Topaz Video 1.7, три уровня резкости, отдельный Neuroserver, минимум NVIDIA 12 GB VRAM / RAM 32 GB. В нашем `slp-2.5.json` уже указан пакет `slp26.zip`: имя файла не означает старую версию 2.5. GUI, наличие весов и реальный запуск ещё не проверены. Сравнить уровни 1/2 с Proteus; не считать рекламные улучшения временной стабильности локальным результатом. Для пробы требуется короткий Export, обычный Preview для этой модели не подходит. Тяжёлый motion blur и нечитаемый текст могут превратиться в выдуманную фактуру.

[Starlight Mini](https://docs.topazlabs.com/topaz-video/project-starlight-series/starlight-mini) — другой кандидат, прежде всего для более повреждённого архива. В версии 1.7 вендор снял требование Pro для локального Mini. Не путать с [Sharp](https://docs.topazlabs.com/topaz-video/project-starlight-series/starlight-sharp) и [Fast 2](https://docs.topazlabs.com/topaz-video/project-starlight-series/starlight-fast-2-local), у которых свои требования/доступ. RTX 4090 сама по себе не доказывает наличие RAM, весов, лицензии и свободной памяти. Для задачи создания навыка не устанавливать Neuroserver/модели и не запускать GPU.

## Точное значение параметров нашей CLI

Основание — вывод установленного `ffmpeg -h filter=tvai_up`, а не значения слайдеров из чужого видео. Параметры применяются только к поддерживающим их моделям.

| CLI | Значение / диапазон | Типичная ошибка |
|---|---|---|
| `details` | Восстановление мелкой фактуры, −1…1 | Путать с Recover Original Detail |
| `blend` | Доля исходного изображения в результате, 0…1 | 1 возвращает много исходных дефектов, а не максимум AI-деталей |
| `blur` | Дополнительная резкость, −1…1 | По имени решить, что положительное значение размывает |
| `preblur` | Anti-alias/deblur, −1…1; минус для aliasing, плюс для размытия | Лечить им геометрический морфинг |
| `noise` | Удаление шума, −1…1 | Положительное ≠ добавить зерно |
| `compression` | Подавление артефактов кодека, −1…1 | Поднимать на чистом источнике |
| `halo` | Удаление ореолов, −1…1 | Перебор тоже создаёт дефекты |
| `prenoise` | Шум перед обработкой, 0…0.1 | Считать эквивалентом финального grain |
| `grain`, `gsize` | Зерно после обработки 0…1, размер 0…5 | Маскировать им неудачный денойз |
| `estimate` | Число кадров оценки 0…100, 0 выключает | Объявлять Static/Manual тем же, что Dynamic |
| `vram` | Доля памяти 0.1…1 | Называть 0.35 жёсткой гарантией потребления в GB |
| `download` | 0 запрещает автоматическую загрузку | Оставить default 1 при только локальном тесте |

В GUI различать Auto/Dynamic/Relative и Manual. Нулевой слайдер относительного режима не означает отсутствие обработки. Для переноса режима в CLI сохранить экспортированную приложением команду и проверить `tvai_pe`/цепочку фильтров. Не угадывать деление любого слайдера на 100. Focus Fix — отдельный приём с уменьшением и увеличением изображения; не подменять им `blur`.

## Практические опыты

Для кожи держать нетронутый исходник рядом; смотреть поры и границы лица на улыбке/повороте. Сначала уменьшить агрессивность details/blur/noise; отдельно проверить blend. Для тканей следить за «ползущими» узорами и исчезновением тонких нитей. Для тёмных планов отличать неправильные levels от шума: поднятие шумоподавления не исправляет ошибку диапазона.

Для двух проходов сначала доказать улучшение одного. [Официальный Second Pass](https://docs.topazlabs.com/topaz-video/advanced-functions/second-pass-enhancement) допускает отдельные промежуточные файлы при нехватке ресурсов. Записывать обе модели и промежуточное разрешение: 2x×2x означает 4x по каждой стороне, не 2x. Нельзя автоматически применить этот механизм к Starlight standalone-фильтрам. Если один проход лучше, второй удалить из рецепта.
