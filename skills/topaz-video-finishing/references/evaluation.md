# Проверка качества и принятие

## Минимальный полезный опыт

Выбрать один и тот же диапазон 3–5 секунд без склейки: поворот лица, волосы/ткань, заметное движение. Добавить тёмный план лишь если это реальный тип материала. Фиксировать source hash, кадры, rational FPS, output dimensions, модель и режим, параметры, версии, GPU, время и лог. Если тест однокадровый, не называть его temporal QA.

Сравнить A: исходник, приведённый обычным scaler к размеру просмотра; B: наш Proteus baseline; C: один кандидат для конкретного дефекта. Метки можно скрыть при субъективной оценке. Держать одинаковые crop, scale, цвет и качество encode. Нельзя сравнивать sharpened full-resolution output с растянутым низкокачественным JPEG и объявлять победу.

Просмотр: целиком на штатной скорости, затем 100% crop в движении и отдельные проблемные кадры. Проверять лицо/зубы/глаза, края, волосы, мелкий текст, фоновые паттерны, flicker, ghosting, склейки, motion blur и синхронизацию звука. Пластик без шума не обязательно лучше живой фактуры. Красивый стоп-кадр не компенсирует мерцание на движении.

Для нашего AI-видео первая интересная новая ветка — Proteus против Starlight Precise 2.6. DLSS подключать только если решается другая задача, например свет/материал; отдельно сравнивать Topaz-only и комбинацию. Дополнительный проход принимается лишь при видимом выигрыше, оправдывающем время и побочные изменения.

## Техническое QC

Существующий CPU helper:

```powershell
& 'E:/Krea_tren_AI/Tools/ResolveMCP/.venv/Scripts/python.exe' 'E:/Krea_tren_AI/Tools/FilmPipeline/media_qc.py' 'E:/Krea_tren_AI/Films/Testfilm/Resolve/Seedance_Finish_v001/Exports/Seedance_Topaz_2x_Master.mov' --frames 265 --fps 24 --size 1984 864
```

Он считает decoded frames, проверяет размеры/average FPS, полностью декодирует короткое медиа и измеряет первый audio stream. Timeout одного subprocess 180 секунд. Для длинного фильма выбирать осмысленные пределы. Результат technical_pass не доказывает cadence, цвет или художественное качество. Дополнительно сопоставить monotonic PTS и интервалы, duration video/audio, sample rate/channels и color tags; для нескольких звуковых дорожек измерить каждую нужную.

Источник 265 кадров / 24 fps имеет видеоинтервал около 11.0417 s; container/audio duration около 11.072 s сам по себе не означает потерю кадра. Сравнивать одинаковые величины, а не округлённые поля из разных stream/container.

## Сохранить результат

Отчёт: hypothesis, source/range, variants, actual command, model-definition hash, completed exit status, runtime, dimensions/FPS/frames, audio/colour checks, visual defects с timecode, verdict и uncertainty. Статусы: prepared → executed → technical_pass → reviewed → user_accepted. Последний не подразумевается молчанием пользователя.

Если модель меняет личность, создаёт ползущую ткань или разрушает нужный рисунок движения, вариант отклонить даже при отличной резкости. PSNR/SSIM против исходника не измеряют правдивость дорисованных пор. Не объявлять «лучше DLSS/SeedVR2» без одинакового локального теста.
