# Минимальная вычислительная лаборатория

`scripts/formula_lab.py` — собственная реализация нескольких семейств для проверки
метода на разных задачах. Python 3, только стандартная библиотека. Без GPU, сети,
провайдеров, дополнительных пакетов и доступа к живому редактору.

Из папки навыка:

```powershell
python scripts/formula_lab.py
python scripts/formula_lab.py --out E:/Krea_tren_AI/output/formula-lab/example-v001
```

Без `--out` выполняет проверки и печатает JSON. С `--out` сначала проверяет модель,
затем создаёт новую папку, CSV и report.json. Существующая папка отклоняется.
Код полезно импортировать с отключённой записью bytecode либо из рабочей копии,
чтобы `__pycache__` не стал частью установленного пакета.

## Что реализовано

- smootherstep: ограниченная квинтическая интерполяция.
- disk_points: равномерная выборка площади диска по заданному seed.
- spaced_points: ограниченный по попыткам наивный rejection baseline, O(attempts·N).
  Для большого мира выбирать другой алгоритм; это не реализация Bridson.
- chirp_phase и decay: аналитическая фаза линейного свипа и огибающая по T60.
- dispersion/group_speed/stiff_mode: демонстрация производной и предельных случаев.
- damper/spring: точные шаги для постоянной цели в пределах шага.
- ik2: плоские два звена, две ветви; недостижимая и неопределённая полностью
  сложенная поза отклоняются. Нет ограничений суставов и 3D pole.
- cfg: скалярный пример алгебры guidance, не запуск диффузии.

## Артефакты

`camera_curve.csv`: 96 начал кадров для 4 s при 24 fps плюс отдельная конечная
граница t=4. Это 97 строк данных, но не 97-кадровый фильм.

`audio_control.csv`: частота/фаза/огибающая на сетке управления 200 Hz. Это не WAV
и не аудиосигнал; для звука нужно вычислять осциллятор на соответствующей аудиосетке.

`disk_points.csv`, `spaced_points.csv`: точки в метрах для небольших примеров.
Их генерация не подтверждает интеграцию в сцену или художественное качество леса.

Шестнадцать групп проверок включают производные, моменты распределения, дистанции,
изменение FPS, прямую кинематику и отклонение некорректных условий. Проверка нескольких
семейств не доказывает универсальную корректность любых будущих формул.
Сохранять версию Python и хеш скрипта из отчёта; результаты визуально/на слух
принимать отдельно. Для реальной задачи расширять проверки под её инварианты.
