# Evidence card

Fields: ID; title; creator; release/date uncertainty; source URLs; access date; source type; promotional relationship; inspection extent; relevant timestamp/section; claim; status; competing account; local implication; next test.

Statuses:
- Observed: actually visible/audible in inspected media; keep timestamp and version.
- Reported: creator or credited crew describes the process; cite the passage.
- Inferred: plausible explanation; name an alternative.
- Locally tested: inputs, method, outputs and limitations retained.
- Unknown: evidence absent or access blocked.

Use a stage table for concept, script, references, identity, staging, generation, curation, compositing, edit, sound, color and delivery. Each stage has evidence and unknowns. Exact recovery generally requires source projects and logs; similar-looking reconstruction does not prove how the original was made.

An adoption card contains: technique, target failure, prerequisites, controlled comparison, success criterion, maximum effort/cost, stop condition and record location. Preserve unsuccessful attempts. A method can be adopted for one shot family while remaining unproven for another.
