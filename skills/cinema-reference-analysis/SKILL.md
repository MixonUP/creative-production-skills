# Recover what the evidence supports

Select references against the brief and a specific learning question. Separate artistic relevance, external recognition and process transparency. A festival sponsored by a tool provider is a useful source with a selection bias, not a universal ranking. Include creator-owned and independently curated sources where useful. Verify current dates and exact work/version.

Record what was inspected: text, stills, excerpts with timestamps, full audiovisual playback, project files or local reproduction. A page containing an embedded video is not proof of having watched it. If access is unavailable, produce a source-grounded research card and leave shot-level observations pending.

## Reconstruct layers

Use [evidence-card.md](references/evidence-card.md). Connect the creative intention to observable scene construction, then to disclosed workflow. Recover script/structure, visual development, identities, camera/blocking, generation, selection, VFX, editing, sound, color and delivery only as supported. Do not infer lenses, model versions, prompts, seeds, budgets or retry counts as facts from appearance.

For viewed shots use stable IDs and timestamps; describe action, screen direction, performance, light, cut motivation and sound. Distinguish a hypothesized reconstruction route from the author's actual method. Mark unobserved stages unknown. Conflicting sources remain a recorded conflict until resolved.

## Transfer rather than imitate

For each useful technique name the problem it solves, conditions, cost, failure mode and smallest local test. Map it to existing assets and tools. Develop original material that tests the same principle. A viewing reference is not automatically licensed as a training/generation input.

Deliver a breakdown, evidence coverage, a proposed local recipe and an experiment. Numeric coverage, if used, is the proportion of explicitly defined stages evidenced, not a percentage of the artist's entire process recovered. Feed tested results to `film-workflow-learning`; do not promote an interview claim to a mandatory production rule.
