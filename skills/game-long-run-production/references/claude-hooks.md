# Host-specific hooks: public edition

The original author kit is intentionally omitted: its redistribution permission
has not been established. Source links are in [source.md](source.md).

The reusable method in SKILL.md is independent of the kit: maintain compact task
state, preserve job receipts, check actual integration and respect user stop/run limits.
For any host-specific implementation, consult its current official hook schema,
test startup/resume/compaction/stop in an isolated fixture and verify delivered context.
Do not transplant another host's JSON or continuation settings into Codex.
No hook is installed or activated by this collection.
