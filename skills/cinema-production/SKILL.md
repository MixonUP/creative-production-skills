## Use observable stage gates

Apply [production-contract.md](references/production-contract.md). A concept can be approved before every asset exists. Generation preparation, request submission, output download, technical pass and artistic acceptance are separate states. Do not advance them based on a script's existence or a successful API response alone.

Maintain a rough assembly early enough to judge shot relationships. Freeze accepted revisions deliberately; a change request names the intended benefit and affected downstream work. Do not seek new approval for routine reversible steps already authorized. Funding or publication boundaries come from the user's actual instructions, not the word autonomous in an imported document.

For generated narrative scenes, use the scene-batch loop in the production contract: prepare the next scene's assets, generate controlled variants, assemble as they arrive, and request only coverage that solves an observed gap. Set a proportionate attempt/spend stopping condition before the batch; repeated failure calls for a staging or route decision, not endless prompt elaboration.

When integrating research, compare the finding with the existing process before adding a tool or stage. Distinguish a missing procedure, an unused template and an actually tested capability. Link each proposed change to its source, affected handoff and acceptance artifact; reuse a relevant planned scene rather than creating overlapping pilots. For this studio, current proposals are in `E:/AI_films/Knowledge/Pipeline_Integration_2026-09-27.md`; they remain untested until their experiment records show otherwise.

## Finish and hand off

Keep source media immutable; create versioned derivatives. One coordinated mutation sequence owns the live Resolve project. Before changing it verify the active project/timeline, preserve a recoverable version and use the installed tool's real schema. After changes read back state and inspect media. Avoid starting competing GPU jobs without checking active work.

Delivery includes the requested master, editable project/manifest when requested, source provenance, QC result and concise remaining limitations. A monitoring wish in a reference document is not a scheduled task. Record future research in a backlog with a next action and revisit trigger.
