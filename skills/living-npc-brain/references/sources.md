# Источники, отбор и пределы доказательств

Проверка 2026-10-03. Отбор по четырём критериям: объясняет механизм, даёт первичное описание, переносим на интерактивную игру и допускает наблюдаемую проверку. Старая фундаментальная работа может быть полезнее свежей демонстрации. «Лучший выбор» здесь означает аргументированный вариант для конкретного проекта; сравнительного испытания всех систем не проводилось.

## Инструменты — первичная документация

- [SQLite FTS5](https://sqlite.org/fts5.html): полнотекстовый поиск. Выбор SQLite базовым хранилищем — наше решение по простоте и контролю; качество русского retrieval нужно проверять.
- [multilingual-e5-small, карточка авторов](https://huggingface.co/intfloat/multilingual-e5-small/raw/main/README.md): многоязычный embedding-кандидат, русский указан. Перед пробой прочитать требования к префиксам, нормализации и длине; локального бенчмарка здесь нет.
- [Mem0 OSS](https://docs.mem0.ai/open-source/overview): библиотека/сервер, настраиваемые LLM/embedder/storage. В просмотренных defaults есть облачные компоненты. Статус self-hosted не доказывает offline.
- [Letta stateful agents](https://docs.letta.com/v1-sdk/concepts/stateful-agents): редактируемые memory blocks и закрепление в контексте; shared blocks требуют осознанного владения данными.
- [LangGraph overview](https://docs.langchain.com/oss/python/langgraph/overview): детерминированные и модельные шаги, сохранение состояния, streaming. Польза для нашей простой очереди ещё не показана.
- [LimboAI](https://github.com/limbonaut/limboai): BT/HSM, blackboard, вариант GDExtension. Совместимость конкретного бинарника с Godot 4.7.2 в этом исследовании не проверена.
- [llama.cpp server](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md): документированы response/schema constraints. URL master изменяемый; для реализации проверять установленный b11371 либо фактический новый закреплённый runtime.
- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS): возможности модельного семейства; при интеграции отличать поддержку модели от возможностей нашей обёртки. Локальные показатели — в [aiwaifu.md](aiwaifu.md).
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper): локальное распознавание через CTranslate2. Выбранный Small CPU проверен ранее, другие размеры здесь не сравнивались.
- [LiveKit turns](https://docs.livekit.io/agents/logic/turns/): ручные ходы, определение окончания речи, перебивания и ложные срабатывания. Основа для будущего сравнения, не установленная часть игры.
- [AIRI](https://github.com/moeru-ai/airi): открытый проект компаньона; Memory Alaya отмечена WIP в прочитанном README. Не принимать чеклист возможностей за доказанный production результат.
- [JARVIS memory tutorial](https://www.youtube.com/watch?v=gqmSKEUpRv8), [репозиторий автора](https://github.com/ruxakK/friday_jarvis2): практический пример Mem0. README ограничивает авторские части private/educational use. Код не копировался; название self-learning не означает обучение весов в ходе разговора.

## Оценка

[LoCoMo, авторский репозиторий](https://github.com/snap-research/LoCoMo) и [работа](https://arxiv.org/abs/2402.17753) посвящены долговременной разговорной памяти и её оценке. Используем принцип проверять память на длинных многоэпизодных разговорах, временных вопросах и источниках. Наши короткие игровые сценарии не являются запуском LoCoMo; показатели разных вендоров нельзя сравнивать без одинакового протокола.

## Что намеренно не объявлено установленным знанием

Внутренний «мозг» Grok Animate/Imagine/Companions не реконструирован. Рецепты многомодельного сознания, обязательного дообучения, постоянного фонового размышления и «идеальной памяти» не приняты без измерений. Недоступный материал не считается прочитанным. Новая схема навыка и сценарии проверены отдельно от поведения будущей игры.

При обновлении меняй только затронутое решение: источник/версия → ожидаемый выигрыш → локальное сравнение → результат и ограничение. Сохраняй отличия между «найдено», «подготовлено», «запущено» и «принято».
