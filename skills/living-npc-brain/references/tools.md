# Выбор инструментов по задаче

Проверено по первичным материалам 2026-10-03; ссылки — [sources.md](sources.md). Это рекомендации для сравнения, а не универсальный рейтинг. Перед внедрением уточняй установленную версию, лицензию, локальность всех компонентов и результат на русском. Не обновляй рабочее окружение ради совпадения со свежим уроком.

## Основной выбор для одного локального NPC

| Задача | Начальный выбор | Когда нужен следующий уровень |
|---|---|---|
| Разговор | уже работающий llama.cpp и текущая модель | другая модель выигрывает на одинаковых сценах по характеру, точности действий и задержке |
| Состояние/Director | небольшой Python-сервис с явной очередью | сложные ветвления, долговечное возобновление и отладка оправдывают LangGraph |
| Память | SQLite, журнал событий, теги/FTS5 | тесты перефразирования проваливаются — добавить embeddings и гибридный поиск |
| Embeddings-кандидат | CPU-проба intfloat/multilingual-e5-small | более крупный encoder/reranker оправдывает прирост recall на нашей русской выборке |
| Действия | typed GDScript, сигналы, небольшая FSM | множество вложенных/прерываемых задач — рассмотреть LimboAI BT/HSM |
| Озвучка | установленный Qwen3-TTS | другой голос/провайдер лучше на одинаковом наборе русских реплик и при совместной GPU-нагрузке |
| Распознавание | установленный faster-whisper CPU | ошибки речи пользователя или задержка требуют другого размера/устройства/model |
| Очередность речи | текущая кнопка записи и явная отмена | по отдельной задаче добавить VAD/turn detection и перебивание; LiveKit — кандидат для развитой потоковой связи |

Это набор для [текущей AIWAIFU](aiwaifu.md), а не требование переносить любой чужой проект на Python. Не добавляй HTTP-слой, если задача уже удобно решается внутри существующего приложения.

## Что дают альтернативы

- **Mem0:** готовые операции извлечения, добавления, поиска и обновления памяти. Полезен при большом объёме однотипной работы с памятью. Проверь фильтры, источники, исправления и удаление. Self-hosted не значит полностью локальный inference: документация на дату проверки содержит облачные LLM/embedding defaults; локальные компоненты нужно выбирать явно.
- **Letta:** состояние агента и редактируемые блоки памяти, закрепляемые в контексте. Рассматривать как вариант архитектуры с ясным владельцем памяти, а не ещё один слой поверх уже управляющего теми же данными Director. Общие blocks требуют проверки изоляции NPC.
- **LangGraph:** смешение детерминированных шагов и LLM, persistence/streaming. Выбирай, когда эти возможности сокращают реальную сложность. Один короткий запрос с валидацией не требует графового фреймворка.
- **LimboAI:** Behavior Trees и иерархические state machines для Godot 4, включая GDExtension. Совместимость конкретной сборки с закреплённым Godot и экспортом должна быть проверена отдельно; название Godot 4 не является таким подтверждением.
- **Convai/Inworld:** кандидаты для сравнения готового сервиса с собственной реализацией. Сопоставь русский, управление характером/действиями, экспорт памяти, latency, офлайн-требование, стоимость и интеграцию именно с нашим движком. Урок Unreal/Unity не означает готовый Godot-плагин. Старые страницы Inworld могут быть перенаправлены; перепроверь текущий продукт.
- **AIRI:** открытый референс интерактивного компаньона с голосом и аватаром. В просмотренном README Memory Alaya отмечена WIP. Используй для изучения решений, не как доказанный заменитель игрового мозга или точную копию Grok.
- **LiveKit:** управление голосовыми ходами и прерываниями; полезен при соответствующем транспортном/продуктовом запросе. Отличай определение наличия речи от понимания, что фраза закончена. Проверяй шум, эхо TTS и ложные перебивания.

## Как выбрать модель и режим исполнения

Сначала измерь текущий вариант. Затем сравни одного обоснованного кандидата на тех же входах, памяти и действиях. Для ограниченной GPU меньшая модель, полностью помещающаяся рядом с TTS, может оказаться полезнее большей с CPU offload; это гипотеза для измерения, не гарантия.

Измеряй русский характер/естественность, обоснованность памяти, исполнение ограниченного контракта, p50/p95 задержки, совместную VRAM, frame time и скорость отмены. Тестируй сначала текст без TTS, затем полную сцену. Изменение модели, промпта, retrieval и голоса одновременно делает причину выигрыша неясной.

llama.cpp документирует JSON/schema constraints, но синтаксис запроса проверяй по закреплённой версии сервера. Grammar уменьшает ошибки формы, а не ошибок смысла. Для решений можно начать со стабильного sampler, для реплик — с умеренной вариативности; точные числа выбираются тестом. Не ставь greedy TTS по аналогии с генерацией JSON.

При очереди на одной GPU обслуживай игрока и текущий звук раньше фоновой рефлексии. Сериализация/ограничение запросов часто полезнее нескольких постоянно работающих больших моделей. Дополнительная «модель эмоций», embeddings на GPU и vision требуют измеренного выигрыша и отдельного бюджета. Известное движку состояние комнаты сначала передавай как данные; анализ изображений нужен для содержания, которого движок не знает.

Обучение LoRA языковой модели рассматривай после выявленного устойчивого стилевого дефекта и накопления правомерного набора примеров. Дообучение не заменяет память о конкретном сохранении. Смена библиотеки сама по себе не добавляет персонажу мотивацию.
